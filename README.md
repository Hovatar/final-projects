# Final Projects — Hovan Boyajian

Public code and reports for my final projects.

## Contents
- [`math104c-final-project-1/`](math104c-final-project-1/) — **MATH 104C Final Project 1**: Numerical Methods for ODEs.
  Eight numerical methods (Euler, Taylor-2, midpoint, modified Euler, Heun, RK4,
  Adams–Bashforth, Adams predictor–corrector) compared on three IVPs, with a
  convergence study and stability discussion. See the folder README and
  `report/report.pdf`.
- [`math104c-final-project-2/`](math104c-final-project-2/) — **MATH 104C Final Project 2**: Numerical Methods for PDEs.
  Five-point finite-difference for the Laplace equation (Gauss–Seidel) and
  Forward, Backward, and Crank–Nicolson schemes for the heat equation (with
  Crout factorization for the tridiagonal solves), plus a multi-mode
  initial-condition experiment and a Poisson manufactured-solution convergence
  check. See the folder README and `report/report.pdf`.
